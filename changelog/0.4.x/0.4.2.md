# 0.4.2 — 2026-10-23

## Added

- **`biorxiv_get_published_version` journal-DOI input** — any DOI outside `10.1101/` and `10.64898/` resolves through `/pubs` to the preprint it was posted as, returned in the same record (`preprintDoi` is the linked preprint); no recorded preprint raises `doi_not_found`. A journal DOI keeps its own components (`10.7554/eLife.55185.sa1`, `….g001`, Wiley's `.x`); only page-format tabs (`.pdf`, `.full`, …) and a `vN` revision are stripped (#74).
- **`biorxiv_list_published_versions` `publisher`** — a journal DOI prefix (`10.7554` for eLife) lists only the bioRxiv preprints published under it, from `/publisher`. `server: "both"` queries bioRxiv alone with a notice, `server: "medrxiv"` and an unrecognized prefix raise `invalid_publisher`, and rows carry no journal name, authors, or abstract (#77).

## Changed

- **`abstract`** — `biorxiv_get_preprint` returns it on the latest revision only, with revisions in ascending version order; the API repeats one abstract on every revision. Listing rows keep their preprint's latest abstract (#71).
- **Record `server`** — `revisions[].server` on `biorxiv_get_preprint` and `preprints[].server` on `biorxiv_list_recent` and `biorxiv_search_preprints` is the `biorxiv` / `medrxiv` enum, valid as any tool's `server` input, not the API's `bioRxiv` / `medRxiv` (#76).
- **Date inputs** — `biorxiv_list_recent` `start_date` / `end_date` declare the `YYYY-MM-DD` pattern in the schema (#76); a date failing it, there or on `biorxiv_search_preprints` and `biorxiv_list_published_versions`, gets an error naming the format.
- **Not-found hints** — suggest `server="both"` only when the call checked one server.

## Fixed

- **Second-slash DOIs** — a DOI such as `10.1101/abc/def` returns not found instead of a retryable outage (#73).
- **`biorxiv_search_preprints` `cursor_mark`** — a malformed token raises `invalid_cursor_mark` instead of `search_unavailable`: after every cursor attempt fails with HTTP 503 or an empty body, one first-page request for the same query settles it (#72).
- **Abstracts** — the literal `\n` and `\"` older bioRxiv abstracts carry read as line breaks and quotes, so section headings no longer run into the next word (#78).
- **`biorxiv_get_fulltext` figures and references** — each figure renders once as an image and its caption, the Download and Open-in-new-tab links are gone, and each reference carries one number (#75).
- **`biorxiv_get_fulltext` formulas** — display and inline formulas render as images in place, with no "Embedded Image" paragraph and no text spliced onto the preceding paragraph (#79).
