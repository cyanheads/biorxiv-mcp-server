# 0.4.0 — 2026-10-15

## Added

- **`biorxiv_list_published_versions`** lists the preprints that appeared as journal articles within a journal publication-date interval, on bioRxiv, medRxiv, or both. Pages of 100 rows per server advance with `cursor`, with per-server pagination; `include_abstract` adds abstracts (#59).
- **`biorxiv_get_fulltext` `omittedTables`** names each table whose cells are not on the article page, by label with the URL that serves them, on every chunk and in the rendered text (#58).

## Changed

- **`biorxiv_get_fulltext` extraction** keeps inline citation, figure, and table labels and each reference entry's text, with the DOI of an entry that has one as a `doi.org` link. Cached extractions from earlier versions are not reused (#58).
- **`biorxiv_get_fulltext` `limit`** has no maximum; a value past the remaining text returns the rest of the article (#62).
- **`biorxiv_search_preprints` `date_from`/`date_to`** advertise the `YYYY-MM-DD` pattern in the input schema, so a malformed date is rejected as an invalid argument; `invalid_date_range` still covers non-calendar dates and reversed bounds (#57).
- **`rate_limited` recovery hints** read "wait the `retryAfter` seconds when present, otherwise a minute or two" on every tool that declares it (#60).

## Fixed

- **`biorxiv_search_preprints` blank dates** — a blank `date_from` or `date_to` reads as unset instead of corrupting the EuropePMC date filter and the `queryEcho` (#57).
- **`Retry-After` of `0` or a past date** is treated as no usable wait across every origin, so the retry wording no longer says to wait 0 seconds (#60).
