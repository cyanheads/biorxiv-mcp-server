# 0.4.3 — 2026-10-25

## Changed

- **Markdown escaping** — `biorxiv_search_preprints` (query echo line, empty-result notice), `biorxiv_list_recent` (category in its notices), and `biorxiv_get_published_version` (upstream error in the journal-DOI notice) escape caller- and upstream-supplied text with `escapeMarkdownInline`. A notice is the same Markdown string on both surfaces; the `queryEcho` object in `structuredContent` keeps the raw values.
- **Framework skills and `scripts/devcheck.ts`** synced from mcp-ts-core 0.13.16 — when a direct dependency's audit block also lists transitive copies, devcheck's security audit counts it as direct only if the copy installed at the project root falls inside a high or critical advisory's vulnerable range.

## Fixed

- **`biorxiv_get_fulltext` short sections** — a section under 200 words whose heading holds a navigation word (`related`, `responses`, `share`, `terms`, …) is no longer dropped, as medRxiv `10.64898/2026.10.13.26365491` section 3.2 was (#80).
- **`biorxiv_get_fulltext` nested reference lists** — a list nested in a reference entry (an edited volume's editors) renders inline in page order instead of as numbered items or being deleted near the article's end; a nested list marked `duplicate` is dropped instead when it holds only list items and the rest of the entry already names every item, as whole words and in list order (#82).
- **Rate limiting** — a 429 with `Retry-After: 0` or an HTTP-date already past takes the exponential backoff of a header-less 429 on every upstream ladder, not four back-to-back requests (#81).
