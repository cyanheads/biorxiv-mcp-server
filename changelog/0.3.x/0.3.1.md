# 0.3.1 — 2026-10-07

## Changed

- **Tool error results carry `data.requestId`** and the text ends with `request <id>`, e.g. `(reason invalid_doi_format · request KKSKM-ZFPUU)` (mcp-ts-core 0.13.10).
- **Client error data omits internals** — stack traces (0.13.7), request context fields (0.13.8), and `data.rootCause` (0.13.13) no longer reach it.
- **Argument rejections name the field path in the hint**, and a JSON-stringified object or an integer sent for a string field is repaired before validation (0.13.9).
- **Upstream fetch errors name the URL by origin only**, e.g. `https://host/…?…`; the EuropePMC `search_unavailable` message embeds that text (0.13.12).
- **`ctx.log` notifications to the client honor `MCP_LOG_LEVEL` and mask sensitive fields** (0.13.11).
- **MCP SDK transport** — `@modelcontextprotocol/server` 2.0.0 → 2.2.0 through the framework (0.13.9, 0.13.11).
- **Docker** — dependencies install in a `deps` stage on the build platform, so the multi-arch build no longer runs Bun under QEMU (0.13.10), and musl-only packages are pruned from the glibc image (0.13.11). The image also drops `ENV MCP_FORCE_CONSOLE_LOGGING`.
- **MCP Registry `server.json`** — npm entries no longer pass `run start:*` arguments, `runtimeHint` is `npx`, and the streamable-http entry sets `MCP_TRANSPORT_TYPE` to `http` (0.13.11).
- **Tool handlers** no longer spread `ctx.recoveryFor(...)` into `ctx.fail` data; the framework fills the declared hint (the hints on the wire are unchanged). Tests read it from the `runToolContract` envelope through a new `envelopeHint` helper.
- **CodeQL workflow** runs one job per language, uploading each under `/language:<language>`.
- **Ignore files** — `.gitignore` and `.dockerignore` cover every `.env*` file (the `.env.example`, `.env.template`, and `.env.sample` templates stay tracked); `.dockerignore` also excludes the MCP Registry token files; `.mcpbignore` adds `/docs/idea.md`, `/logs/`, and `/.cache/`; `package.json` `files` adds `!dist/*.mcpb`.
- **Framework skills and scripts** synced to 0.13.13 — new `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts` (run by the Dockerfile), `lint:packaging` checks 13–16, `release:github -- --check`, and corrected devcheck TODO and tracked-secret scans.
- **Docs** — `AGENTS.md` and `CLAUDE.md` error-contract, `ctx` table, command, and skill-list wording; README tool sections condensed and a `LOG_TOOL_FAILURE_PAYLOADS` row added; `.env.example` rows for opt-in framework settings (including `LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, `LOG_LLM_INTERACTIONS`, the `OTEL_EXPORTER_OTLP_{TRACES,METRICS,LOGS}_ENDPOINT` overrides).
