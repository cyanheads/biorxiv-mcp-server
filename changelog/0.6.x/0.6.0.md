# 0.6.0 — 2026-11-21

## Changed

- **`biorxiv_search_preprints`** requests 10 upstream rows by default and includes abstracts when available. (#94)
- **`biorxiv_get_preprint` and `biorxiv_get_fulltext`** suggest searching both servers after a confirmed single-server miss and offer a conditional journal crosswalk for unfamiliar DOI prefixes. (#95)

## Removed

- **`biorxiv_get_fulltext`** no longer includes `body` or `responseBody` in `structuredContent.error.data` for a captured article-origin HTTP 400. The HTTP status remains available.

## Fixed

- **`biorxiv_search_preprints`** normalizes citation-form author names and echoes the normalized name used for search. (#91)
- **`biorxiv_search_preprints`** diagnoses clear query syntax defects only after Europe PMC reports zero hits, with copyable literal syntax in structured notices when it can suggest a repair. (#92)
- **`biorxiv_search_preprints`** omits the cursor on short upstream pages and can retain it on full pages whose rows lack DOIs. (#93)
- **Record categories** trim and lowercase `category` and `preprintCategory`, omitting blank values. (#96)
