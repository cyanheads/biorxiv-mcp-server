# 0.2.0 — 2026-07-11

## Added

- **`biorxiv_get_fulltext`** — retrieves a preprint's full text as best-effort Markdown extracted from the rendered HTML article page (`www.{server}.org/content/{doi}v{N}.full`); there's no keyless JATS source, so this extracts `contentFormat: "html-markdown"`, not structured JATS. Resolves the latest version via the details API, pages long articles with `offset`/`limit` character chunking, and routes PDF-only or blocked pages to a typed `fulltext_unavailable` error pointing at `biorxiv_get_preprint`. medRxiv's Cloudflare edge can block programmatic fetches from some hosts — bioRxiv coverage is more reliable. New deps: `defuddle` `^0.19.0`, `linkedom` `^0.18.12`. [#19](https://github.com/cyanheads/biorxiv-mcp-server/issues/19)
- **`biorxiv_search_preprints`** — optional `author` parameter maps to an EuropePMC `AUTH:"…"` field query, ANDed with the keyword query; `query` is now optional when `author` is supplied, so author-only searches work while existing query-only calls are unchanged. [#19](https://github.com/cyanheads/biorxiv-mcp-server/issues/19)
