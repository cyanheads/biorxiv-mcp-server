# 0.2.6 — 2026-08-25

## Fixed

- **Docker build stage no longer fails under emulation** — the build stage now pins `FROM --platform=$BUILDPLATFORM oven/bun:1.4.0 AS build` instead of building for the target platform. On an arm64 build host, the `linux/amd64` leg previously ran under QEMU, where Bun 1.4.0's JavaScriptCore aborted with a spurious MemoryExhaustion assertion during `bun run build`; the stage only emits platform-independent JavaScript and `dist/` is the sole artifact copied forward, so it never needed emulation. This is what blocked 0.2.5's GHCR publish — that release has no image on GHCR. `0.2.6` is the first tagged image, and it also carries `@cyanheads/mcp-ts-core` 0.12.3 and the other 0.2.5 changes that published everywhere else.
