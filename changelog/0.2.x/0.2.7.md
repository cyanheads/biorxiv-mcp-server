# 0.2.7 — 2026-09-19

## Added

- **`inputAliases`** lets `biorxiv_list_recent` accept `date_from`/`date_to` and `biorxiv_search_preprints` accept `start_date`/`end_date`, so a caller reusing the sibling tool's field names still succeeds. Framework 0.13.4 also rewrites a case-style variant of any declared key to its canonical form and repairs a JSON-stringified array after a failed parse. Advertised `inputSchema` is byte-identical to 0.2.6.
- **Hosted endpoint** — `server.json` lists `https://biorxiv.caseyjhand.com/mcp` as a `streamable-http` remote, and the README documents the public instance.
- `.github/workflows/codeql.yml` — a CodeQL static-analysis workflow.

## Changed

- **Tool-argument rejections** return `isError` with `structuredContent.error.code` `-32602`; the text carries a `Recovery:` hint and `data.reason: "invalid_arguments"`, and an omitted required field now reads as missing rather than a generic type error (mcp-ts-core 0.12.7, 0.13.3).
- **Tool error text** closes with `(reason <reason>)`, plus ` · not retryable` when `data.retryable` is false (0.13.5).
- **Upstream 5xx handling** — an HTTP 500 now retries as `ServiceUnavailable`; a 501 does not retry (0.12.4).
- **Session mode** — `src/index.ts` now declares `createApp({ sessionMode: 'stateless' })`, so an HTTP source run with `MCP_SESSION_MODE` unset serves stateless instead of resolving `auto` to stateful; an explicitly set `MCP_SESSION_MODE` still overrides it. The Docker image and `.env.example` already pinned `stateless` (option from 0.13.1).
- **Env config** — every server env var now reads an empty or unsubstituted `${…}` value as unset (0.13.0), not just the three fields that previously carried a placeholder guard.
- Graceful shutdown — `SIGTERM`/`SIGINT` now end the process explicitly (0.13.1).
- Server `instructions` rewritten to name `biorxiv_get_fulltext`.
- Repo tooling — Bun engines floor raised to `>=1.4.0`; skill tree moved `skills/` → `framework-skills/`; `.env.example` corrections; issue-form length budgets tightened.
