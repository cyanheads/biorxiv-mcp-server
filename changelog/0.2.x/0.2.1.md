# 0.2.1 — 2026-08-09

## Changed

- **`biorxiv_get_published_version`** — `server` gains `"both"` and now defaults to it, fanning out across bioRxiv and medRxiv in parallel (the two servers share the `10.1101/` prefix, so a single-server default silently missed records held by the other). New required output field `server` names which server answered. [#34](https://github.com/cyanheads/biorxiv-mcp-server/issues/34)

## Fixed

- **`biorxiv_get_preprint`** — a DOI is now reported `not_found` only when every attempted server answered with an empty collection; a server that failed to respond leaves absence unestablished and the DOI is classified `upstream_unavailable` (retryable) instead. Each `failed[]` entry carries a new `reason` (`not_found`, `invalid_doi_format`, `upstream_unavailable`) and `retryable` flag; the batch-level thrown error follows the same discrimination via a new declared `upstream_unavailable` contract entry. [#32](https://github.com/cyanheads/biorxiv-mcp-server/issues/32)
- **`biorxiv_get_published_version`** — `doi_not_found` recovery hint no longer asserts the preprint is unpublished; it now points at retrying with `server="both"` or checking `publishedJournalDoi`. A server that fails to respond throws a new retryable `upstream_unavailable` instead of being folded into `doi_not_found`. [#34](https://github.com/cyanheads/biorxiv-mcp-server/issues/34)
- **`biorxiv_list_recent`** — under `server="both"`, a per-server cursor past the last page now sets a new `exhausted: true` flag instead of its `total: 0` reading as "nothing in the interval"; a server that fails to answer is named in a new top-level `failed[]` (rather than silently dropped) and in the response `notice`, marking the result set as partial. `ctx.enrich.notice` is last-wins, so every applicable qualification (failed servers, exhausted cursors, empty results) is now composed into one notice string. [#35](https://github.com/cyanheads/biorxiv-mcp-server/issues/35), [#39](https://github.com/cyanheads/biorxiv-mcp-server/issues/39)
- **README** — `biorxiv_get_published_version` section referenced a `published` field; corrected to `publishedJournalDoi`, matching the actual `biorxiv_get_preprint` output.
