# 0.2.8 — 2026-09-22

## Fixed

- **`EuropePmcService`** retries an HTTP 200 body with no `resultList` instead of reading it as zero matches; a body that persists raises `invalid_cursor_mark` on a cursor page or `search_unavailable` on a first page ([#43](https://github.com/cyanheads/biorxiv-mcp-server/issues/43), [#47](https://github.com/cyanheads/biorxiv-mcp-server/issues/47)).
- **`biorxiv_list_recent` category filter** now matches case-, `_`-, `-`-, and `/`-insensitively in the API's own spelling; a server that silently ignored the filter is dropped with a notice, or raises `invalid_category` when every server ignored it. Three taxonomy entries the API never filters on (`Epidemiology` and `Clinical Trials` on bioRxiv, `Vascular Medicine` on medRxiv) are removed from `biorxiv_list_categories` ([#45](https://github.com/cyanheads/biorxiv-mcp-server/issues/45)).
- **`biorxiv_get_published_version`** resolves `10.64898/` DOIs, which `/pubs` keyed by preprint DOI never parses: it now falls back to the preprint's `/details` record for the journal DOI, then `/pubs` keyed by that. When the reverse lookup also finds nothing, the journal DOI still comes back with a notice rather than a false `doi_not_found` ([#46](https://github.com/cyanheads/biorxiv-mcp-server/issues/46)).
- **DOI input** across `biorxiv_get_preprint`, `biorxiv_get_published_version`, and `biorxiv_get_fulltext` now accepts a `doi.org`/article URL, a `doi:` label, and a trailing `vN`/`.full` suffix, normalizing to the bare DOI before any API call. `biorxiv_get_fulltext` takes a `version` input honoring a DOI's `vN` suffix, raising `version_conflict` when they disagree and `version_not_found` when the preprint lacks the requested revision ([#50](https://github.com/cyanheads/biorxiv-mcp-server/issues/50)).
- **`biorxiv_get_fulltext` `wordCount`** is now counted from the Markdown the tool actually serves, not the extractor's own figure, which measured its intermediate HTML and undercounted articles by an order of magnitude. The full-text cache key moved to `fulltext/v2` so no stale entry is read back ([#51](https://github.com/cyanheads/biorxiv-mcp-server/issues/51)).
