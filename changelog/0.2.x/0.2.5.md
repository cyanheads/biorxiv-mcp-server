# 0.2.5 — 2026-08-25

## Added

- **`.github/CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`** — community-health files, alongside the existing `SECURITY.md` and issue forms.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.11.1` → `^0.12.3` — adopts the SDK v2 migration (`@modelcontextprotocol/server` `^2.0.0`, was `@modelcontextprotocol/sdk` `^1.30.0`). The HTTP endpoint now serves protocol revision 2026-07-28 alongside the 2025-era revisions it already served.
- **Tool inputs are strict** — a key not declared on a tool's input schema is now rejected by name instead of silently ignored, and every `inputSchema` advertises `additionalProperties: false`. None of this server's 6 tools declare `.passthrough()`/`.catchall()`, so the change applies unmodified across the surface.
- **`.env.example`** — `MCP_SESSION_MODE` is now set to `stateless` rather than left commented at the old `stateful` default, so copying the example into `.env` for a source run now serves stateless sessions unless overridden. New commented options documented for HTTP resumability, GC-pressure relief, and log rate limiting.
- **`.github/SECURITY.md`** — vulnerability-report contact moved to `security@caseyjhand.com`.
- **`Dockerfile`** — the production `bun install` and the OTEL `bun add` now pass `--omit=peer`, dropping the framework's optional peer tiers (test runner, service SDKs, parsers) from the runtime image.
