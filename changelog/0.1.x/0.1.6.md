# 0.1.6 — 2026-05-23

## Fixed

- **`biorxiv_get_preprint` / `biorxiv_get_published_version`**: recovery hints updated to include `10.64898/` prefix alongside `10.1101/` for valid DOI formats ([#8](https://github.com/cyanheads/biorxiv-mcp-server/issues/8), [#9](https://github.com/cyanheads/biorxiv-mcp-server/issues/9))
- **`biorxiv_search_preprints`**: date validation errors now use `ctx.fail()` with a recovery hint instead of a generic error ([#10](https://github.com/cyanheads/biorxiv-mcp-server/issues/10))
- **`biorxiv_search_preprints`**: `server="both"` query scoped to bioRxiv/medRxiv publishers in EuropePMC ([#11](https://github.com/cyanheads/biorxiv-mcp-server/issues/11))
- **`biorxiv-service`**: funder `"NA"` string normalized to absent rather than surfaced as a funder name ([#12](https://github.com/cyanheads/biorxiv-mcp-server/issues/12))
- **`biorxiv_get_preprint`**: format-invalid DOIs in batch mode route to `failed[]` instead of aborting the entire request ([#13](https://github.com/cyanheads/biorxiv-mcp-server/issues/13))
- **`biorxiv_list_recent`**: category validation scoped to the target server's taxonomy rather than the union of both ([#14](https://github.com/cyanheads/biorxiv-mcp-server/issues/14))
- **`biorxiv_search_preprints`**: whitespace-only queries rejected via `.trim().min(1)` refine ([#15](https://github.com/cyanheads/biorxiv-mcp-server/issues/15))
- **`biorxiv_list_recent`**: cursor-past-total message distinguished from empty filter results ([#16](https://github.com/cyanheads/biorxiv-mcp-server/issues/16))
- **`biorxiv_list_recent`**: category input trimmed before taxonomy validation ([#16](https://github.com/cyanheads/biorxiv-mcp-server/issues/16))
