# 0.1.9 — 2026-05-28

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.9` → `^0.9.13` — adopts: configurable inbound request-body cap (`MCP_HTTP_MAX_BODY_BYTES`, default 1 MiB, rejects with 413 before body parsing); HTTP session-init gate rejects non-`initialize` requests without `Mcp-Session-Id` with 400; expected client errors (401/403/400/404) now log at `warning` instead of full error pipeline with stack traces; `GET /mcp` surfaces `package.json` `keywords`.
- **`src/index.ts`** — `landing: { requireAuth: false }` set explicitly; the hosted server serves its full tool/resource inventory to unauthenticated callers regardless of `MCP_AUTH_MODE`.
- **`src/config/server-config.ts`** — `BIORXIV_MAILTO` now preprocessed to strip MCPB placeholder strings (`${user_config.X}`) before `z.email()` validates, preventing a crash when the optional field is left blank in Claude Desktop.
- **`biorxiv_search_preprints`** — EuropePMC search failure now raised via `ctx.fail('search_unavailable', …)` instead of the bare `serviceUnavailable()` factory, aligning with the typed error contract.

## Fixed

- **`@biomejs/biome`** `^2.4.15` → `^2.4.16`
