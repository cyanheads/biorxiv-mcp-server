# 0.1.7 — 2026-05-24

## Fixed

- **`biorxiv_list_recent`**: `server="both"` with a server-specific category now routes the filter only to the server whose taxonomy includes it; a `category_note` output field explains which server the filter applied to ([#17](https://github.com/cyanheads/biorxiv-mcp-server/issues/17))
- **`biorxiv_search_preprints`**: enrichment with `server="medrxiv"` no longer routes through bioRxiv; routing is based on `input.server`, not DOI prefix — `10.1101/` is unreliable as a discriminator since both servers share it ([#18](https://github.com/cyanheads/biorxiv-mcp-server/issues/18))
- **`biorxiv-service`**: per-server category membership checks now use pre-built `Set` instances instead of constructing a new `Set` per call
