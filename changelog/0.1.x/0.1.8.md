# 0.1.8 — 2026-05-24

## Changed

- **`services/shared.ts`** — extracted `asRc`, `detectHtmlError`, and `SERVER_VERSION` from `biorxiv-service.ts` and `europe-pmc-service.ts` into a shared module; eliminates the duplicate definitions that existed in both service files.
- **`SERVER_VERSION`** — corrected stale `'0.1.0'` string to the current version in `services/shared.ts`.
- **`biorxiv-search-preprints` `format()`** — simplified from ~40 lines to 3 via `EnrichedPreprint` type hoisted to module scope; `formatResult` now takes the preprint directly instead of reconstructing separate `revisions[]` and `epmc` objects.

- **`@cyanheads/mcp-ts-core`** ^0.9.6 → ^0.9.9 (`@hono/node-server` ^2.0.3 → ^2.0.4, `fast-check` moved to optional peer dep, fuzzTool pre-parse fixes, `git-wrapup` skill added).

- **`skills/release-and-publish`** — v2.5 → v2.6 (artifact verification step, structured push guidance, MCP Registry URL updated).
- **`CLAUDE.md` / `AGENTS.md`** — "Close the loop on issues" core rule added; framework version reference updated to `^0.9.9`; structure diagram updated for `services/shared.ts`.
