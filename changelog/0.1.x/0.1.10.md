# 0.1.10 — 2026-05-30

## Added

- **`biorxiv_search_preprints`** — `enrichment.totalFound` now carries the raw `hitCount` from EuropePMC (the true upstream grand total), not the count of DOIs returned. Agents can now tell whether raising `limit` would yield more results. Closes [#22](https://github.com/cyanheads/biorxiv-mcp-server/issues/22).
- **`biorxiv_search_preprints`** — `enrichment.queryEcho` echoes the parameters sent to EuropePMC (`query`, `server`, `date_from`, `date_to`, `limit`). Closes [#22](https://github.com/cyanheads/biorxiv-mcp-server/issues/22).
- **`biorxiv_search_preprints`** — `enrichment.notice` surfaces empty-result recovery hints via `ctx.enrich.notice()`; replaces the removed `message` output field.
- **`biorxiv_list_recent`** — `enrichment.notice` surfaces empty-result and cursor-overshoot recovery hints via `ctx.enrich.notice()`.
- **`biorxiv_list_recent`** — `enrichment.categoryNote` surfaces per-server category routing notes via `ctx.enrich()`; replaces the removed `category_note` output field.
- **`EuropePmcSearchResult`** — new export from `src/services/europe-pmc/types.ts`; `EuropePmcService.search()` now returns `{ hitCount, results }` instead of `EuropePmcResult[]`.

## Changed

- **`biorxiv_search_preprints`** output schema — `total_from_search` removed; `message` removed. Both concerns now live in the `enrichment` block (`totalFound`, `notice`), which reaches both `structuredContent` and `content[]` via the framework trailer.
- **`biorxiv_list_recent`** output schema — `message` and `category_note` removed. Both concerns now live in the `enrichment` block (`notice`, `categoryNote`).
- **`@cyanheads/mcp-ts-core`** `^0.9.13` → `^0.9.16` — framework adoption for `ctx.enrich`, `enrichment:` block, and `enrichmentTrailer:` in the `tool()` builder.
