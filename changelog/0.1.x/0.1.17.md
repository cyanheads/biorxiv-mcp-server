# 0.1.17 — 2026-07-11

## Changed

- **Tool descriptions** (`biorxiv_get_preprint`, `biorxiv_search_preprints`, `biorxiv_list_recent`, `biorxiv_list_categories`) — dropped backend/framework mechanics from advertised text (the EuropePMC-backend note, `ctx.enrich.total()` internals, "applied server-side", "static and maintained in-server"); `biorxiv_get_preprint`'s "full-text/PDF links" overclaim corrected to "JATS XML full-text links" (no PDF field is returned). `README.md` and `docs/design.md` mirrors updated to match. [#26](https://github.com/cyanheads/biorxiv-mcp-server/issues/26)

## Fixed

- **`normalizeUpstreamText()`** (`src/services/shared.ts`) strips Highwire/JATS export artifacts — small-caps sentinels (including the `AO_SCPLOWBSTRACTC_SCPLOW` "Abstract" heading fused onto the first sentence), whole `O_FIG…C_FIG` figure blocks, `org.highwire.dtl.*` object references, and inline HTML tags — from titles and abstracts before they reach either `structuredContent` or rendered `content[]`. Applied in `normalizeRevision()` and `getPublishedVersion()` (`src/services/biorxiv/biorxiv-service.ts`) and `EuropePmcService.search()` (`src/services/europe-pmc/europe-pmc-service.ts`). [#25](https://github.com/cyanheads/biorxiv-mcp-server/issues/25)
- **`biorxiv_get_preprint`**'s `content[]` now renders all 15 `RevisionSchema` fields per revision — `title`, `authors`, `authorCorresponding`, `authorCorrespondingInstitution`, `category`, `funder`, and `server` were previously omitted, silently dropping revision-specific data on the text-only path that `structuredContent` already carried. [#31](https://github.com/cyanheads/biorxiv-mcp-server/issues/31)
