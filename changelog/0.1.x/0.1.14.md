# 0.1.14 — 2026-06-12

## Added

- **`HEALTHCHECK`** in `Dockerfile` — bun-native `fetch` against `/healthz` (the slim runtime ships no curl/wget); `ARG APP_VERSION` now feeds the `org.opencontainers.image.version` OCI label.
- **`scripts/clean-mcpb.ts`** — post-`mcpb pack` cleaner wired into `bundle`: runs `mcpb clean`, then strips dependency-shipped agent docs nested under `node_modules/**` (`skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.

## Changed

- **`createApp()` identity** — `src/index.ts` now sets `name` and `title` explicitly to `biorxiv-mcp-server` so the served identity is the unscoped machine name on every surface, not the npm scope.
- **`biorxiv_search_preprints` enrichment** — the upstream EuropePMC grand total moved from the `totalFound` field written via `ctx.enrich({ … })` to `totalCount` written via `ctx.enrich.total(hitCount)`.
- **`scripts/lint-packaging.ts`** — added bundle-content guards (dev dirs excluded at bundle root; `.mcpbignore` patterns anchored so they don't strip `node_modules/**` runtime paths; critical runtime paths preserved), a post-bundle check that a built `.mcpb` carries zero `node_modules` agent-doc entries, and an identity check that `name`/`title` in the entrypoint and `display_name` in `manifest.json` equal the unscoped package name.
- **`scripts/check-framework-antipatterns.ts`** — new rule flags `z.coerce.boolean()` on env flags (`Boolean("false")` is `true`, so the flag can't be disabled via env — use `z.stringbool()`); comment lines are skipped so a rule's own JSDoc doesn't self-trigger.
- **`.mcpbignore`** — anchored the `/.claude/`, `/.agents/`, `/skills/` dev-dir patterns to root.

## Dependencies

- **`@cyanheads/mcp-ts-core`** `^0.9.21` → `^0.10.6`
- **`@types/node`** `^25.9.1` → `^25.9.3`
