# 0.1.16 — 2026-07-11

## Added

- **Socket supply-chain scanner** (`@socketsecurity/bun-security-scanner` `^1.1.2`) wired via `bunfig.toml`'s `[install.security]` — scans every package for malware, typosquats, and CVEs before install.
- **`minimumReleaseAge`** install guard (`bunfig.toml`) — blocks package versions published less than 3 days ago; `@cyanheads/mcp-ts-core` is excluded via `minimumReleaseAgeExcludes` so framework releases still adopt same-day.
- **`.github/SECURITY.md`** — disclosure policy: private reports via GitHub's Security tab or casey@caseyjhand.com.
- **`.gitattributes`** — LF line-ending normalization, binary-asset markers, and `linguist-generated` markers for `bun.lock`/`CHANGELOG.md`/`docs/tree.md`.

## Changed

- **`Dockerfile`** — base image pinned `oven/bun:1.3` → `oven/bun:1.3.14` (both stages); build stage now runs `bun install --ignore-scripts`, avoiding native-postinstall failures under Bun; BuildKit cache mounts (`--mount=type=cache,target=/root/.bun/install/cache`) persist the install cache across builds.
- **`devcheck.config.json`** — `depcheck.ignores` gains the Socket scanner; `outdated.allowlist` gains `@biomejs/biome`, `@types/node`, and `typescript` as deliberately held tooling pins.
- **`package.json` identity** — `author` normalized to `Casey Hand <casey@caseyjhand.com> (https://caseyjhand.com)`; `packageManager` `bun@1.3.2` → `bun@1.3.14`.
- **Bundled skills + devcheck scripts re-synced** to the `^0.10.14` framework — propagates the git-wrapup tag-signing safeguards, the security-flag changelog convention (source-code fixes only, mirrored into this project's own `changelog/template.md`), and the devcheck Outdated gate's skip logic for versions held by `minimumReleaseAge`.

## Fixed

- **`SERVER_VERSION`** (`src/services/shared.ts`) — was a hardcoded `'0.1.11'` literal that had drifted from every release since and leaked into outbound `User-Agent` headers; now derives from `package.json` via a typed JSON import, so it can't drift again. [#28](https://github.com/cyanheads/biorxiv-mcp-server/issues/28)

## Dependencies

- **`@cyanheads/mcp-ts-core`** `^0.10.9` → `^0.10.14` — a five-version hop spanning the supply-chain hardening and Docker/lint fixes adopted above, plus an internal js-yaml v4→v5 migration (no consumer-visible change for this server).
- **`@biomejs/biome`** `^2.5.0` → `2.5.2` (pinned exact)
- **`@types/node`** `^26.0.0` → `26.1.0` (pinned exact)
- **`tsc-alias`** `^1.8.17` → `^1.9.0`
- **`vitest`** `^4.1.9` → `^4.1.10`
- Transitive advisories on `js-yaml`, `hono`, and `vite` cleared via lockfile re-resolve — `bun audit` reports zero vulnerabilities.
