# 0.1.13 — 2026-06-04

## Fixed

- **`biorxiv_get_published_version` description** referenced non-existent field `published` — corrected to `publishedJournalDoi`, the actual normalized output field ([#23](https://github.com/cyanheads/biorxiv-mcp-server/issues/23)).
- **`biorxiv_get_published_version` `doi_not_found` recovery hint** instructed agents to look for `"NA"` — stripped by normalization before the field ever reaches a handler. Updated to check `publishedJournalDoi` absence ([#23](https://github.com/cyanheads/biorxiv-mcp-server/issues/23)).
- **`biorxiv_search_preprints` `enriched: false` cases** were indistinguishable — transient service errors and not-found (DOI not indexed) shared the same branch with no discriminating signal ([#21](https://github.com/cyanheads/biorxiv-mcp-server/issues/21)).

## Added

- **`enrichment_error` field** on `biorxiv_search_preprints` output — `"service_error"` (transient, retry may help) or `"not_found"` (DOI not indexed on target server; EuropePMC fallback is authoritative). Present only when `enriched: false` ([#21](https://github.com/cyanheads/biorxiv-mcp-server/issues/21)).
- **`format()` renders enrichment failure reason** — human-readable message distinguishes service errors from not-found cases in the text output ([#21](https://github.com/cyanheads/biorxiv-mcp-server/issues/21)).
- **Tests** — 6 new cases covering `enrichment_error` values and `format()` rendering for both failure reasons.
