# 0.1.12 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.16 → ^0.9.21` — adopts three framework fixes: per-request logs and traces now carry fresh request + trace/span IDs instead of the frozen boot context; `fetchWithTimeout` strips query-string secrets (e.g. `?api_key=`) from error messages and logs; `withRetry` fails fast on non-retryable errors and `ctx.fail` auto-populates the `retryable` flag.
- **Client config key** renamed from `"biorxiv"` to `"biorxiv-mcp-server"` in README stdio/npx/Docker snippets.
- **Plugin manifest args** simplified — `["-y", "@cyanheads/biorxiv-mcp-server"]` replaces the redundant `run start:stdio` positional args in `.claude-plugin/plugin.json` and `.codex-plugin/mcp.json`.
- **Skills re-synced** to framework `0.9.21` — `add-service`, `add-tool`, `api-canvas`, `api-context`, `api-linter`, `api-utils`, `design-mcp-server`, `release-and-publish` updated; `api-mirror` and `orchestrations` added.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.9.16 → ^0.9.21`
- `vitest` `^4.1.7 → ^4.1.8`
