# 0.1.15 — 2026-06-20

Framework maintenance — adopts `@cyanheads/mcp-ts-core` `^0.10.6` → `^0.10.9` and re-syncs the bundled skills and devcheck scripts.

## Added

- **`scripts/check-dependency-specifiers.ts`** — new devcheck step (`Dependency Specifiers`, `--no-dep-specifiers`) that hard-fails on floating specifiers (`latest`, `*`, dist-tags) in `package.json`'s dependency sections and `bun.lock`'s `workspaces` map. Catches a `bun update --latest` writing a literal `latest` dist-tag into the lock's workspace map, which would otherwise let the next `bun install` re-resolve past the `package.json` range. Static and local — runs in the default and `--fast` passes.

## Changed

- **`scripts/lint-packaging.ts`** — gains check 10: validates `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, and `.codex-plugin/mcp.json` for non-empty descriptions, unscoped machine name in display fields, and the full `package.json` name in the `npx -y` install arg (an unscoped install arg for a scoped package is a guaranteed install 404).
- **`devcheck.config.json`** — added `packaging.pluginManifests: true`, gating check 10. The `devcheck` Packaging gate, previously skipped unless `manifest.json` existed, now also runs when a plugin manifest is present.
- **Bundled skills + devcheck scripts re-synced** to the `^0.10.9` framework — propagates the fresh-scaffold devcheck guards (git-dependent checks skip when `.git` is absent), the `check-skill-versions` worktree-deletion guard, and seven upstream `SKILL.md` `metadata.version` bumps.

## Dependencies

- **`@cyanheads/mcp-ts-core`** `^0.10.6` → `^0.10.9` — adds the `ctx.content` collector for image/audio content blocks (bytes ride `content[]` only, never `structuredContent`), classifies SELECT-shaped Canvas SQL prepare failures as `invalid_sql` with DuckDB binder detail, fixes `DuckdbProvider.describe({ tableName })` ambiguous-column binder errors, and corrects `OTEL_SERVICE_NAME` seeding docs.
- **`@biomejs/biome`** `^2.4.16` → `^2.5.0`
- **`@types/node`** `^25.9.3` → `^26.0.0`
- **`vitest`** `^4.1.8` → `^4.1.9`
