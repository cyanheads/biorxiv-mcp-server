# 0.1.1 — 2026-05-21

## Added

- `BiorxivApiService` (`src/services/biorxiv/`) — wraps the bioRxiv content API (`/details`, `/pubs`, `/publisher` endpoints) with domain-typed responses, `BIORXIV_MAILTO` User-Agent, and two-server fan-out via `Promise.allSettled`.
- `EuropePmcService` (`src/services/europe-pmc/`) — wraps the EuropePMC REST search endpoint for preprint keyword search.
- `src/config/server-config.ts` — lazy-parsed server config (`BIORXIV_MAILTO`, `BIORXIV_API_BASE_URL`, `EUROPEPMC_API_BASE_URL`) via `parseEnvConfig`.
- Five tool definitions registered in `createApp()`:
  - `biorxiv_list_categories` — returns valid subject category strings for bioRxiv and medRxiv.
  - `biorxiv_list_recent` — date-range browser with per-server pagination state when `server="both"`.
  - `biorxiv_get_preprint` — DOI lookup with revision list, abstract, and full crosswalk metadata.
  - `biorxiv_get_published_version` — published-version crosswalk (journal, DOI, licence) for accepted preprints.
  - `biorxiv_search_preprints` — EuropePMC relevance search enriched via the bioRxiv details endpoint.
- Barrel export `src/mcp-server/tools/definitions/index.ts`.
- Service tests: `tests/services/biorxiv/biorxiv-service.test.ts`, `tests/services/europe-pmc/europe-pmc-service.test.ts`.
- Tool tests for all five definitions (sparse-payload cases included).
- Server-level `instructions` in `createApp()` orienting the model to the tool surface.

## Changed

- `src/index.ts` — replaced echo placeholder with `allToolDefinitions` barrel, added `setup()` to initialize both services.
- `scripts/list-skills.ts` — resolve skills dir relative to project root (not CWD); parallelize skill loading; fix `|` vs `>` block-scalar handling; add `stripQuotes`; guard undefined array access.

## Removed

- Echo tool (`src/mcp-server/tools/definitions/echo.tool.ts`) and its test.
