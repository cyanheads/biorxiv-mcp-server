# 0.1.18 — 2026-07-11

## Added

- **`biorxiv_search_preprints`** — optional `cursor_mark` input pages through ranked EuropePMC results; threads into `EuropePmcService.search()` as `SearchOptions.cursorMark` (defaults to `*`, EuropePMC's first-page cursor). `nextCursorMark` appears in `enrichment` (and echoed in `queryEcho.cursor_mark`) when more pages exist, absent on the last page — EuropePMC omits the field itself once results are exhausted. [#30](https://github.com/cyanheads/biorxiv-mcp-server/issues/30)

## Fixed

- **`biorxiv_list_recent`** — under `server="both"`, a category exclusive to one taxonomy (e.g. `Neuroscience`) now queries only the owning server, instead of merging its filtered page with an unfiltered page from the other. Categories shared by both taxonomies (`Epidemiology`, `Pathology`) still fan out to both servers; `categoryNote` reworded to match. [#27](https://github.com/cyanheads/biorxiv-mcp-server/issues/27)
- **`biorxiv_list_recent`** and **`biorxiv_search_preprints`** — both reject calendar-impossible dates (`2024-02-30`, `2024-04-31`, `2023-02-29`) before any upstream call, via new `isValidCalendarDate()` (`src/services/shared.ts`), which round-trips `Date.UTC()` components against the parsed input. The existing `YYYY-MM-DD` shape regex accepted these, and `new Date()` silently rolled them into the following month rather than rejecting. Valid leap days (`2024-02-29`) are unaffected. [#29](https://github.com/cyanheads/biorxiv-mcp-server/issues/29)
