# 0.5.1 — 2026-10-29

## Added

- **`biorxiv_list_recent` `newPreprints`**: each server's `pagination` entry and `content[]` summary line report the API's `count_new_papers`, the preprints whose first version posted in the interval for the applied filters. Omitted when the API sends no readable count (#86).

## Changed

- **`biorxiv-guide` Agent Skill** 1.0 → 1.1: drops the "wrap every `OR` in parentheses" gate and points new-preprint counting at `newPreprints`.
- **`biorxiv_list_recent` `total` description** states that it counts revision rows (#86).

## Fixed

- **`biorxiv_search_preprints` `OR` queries**: the trimmed `query` is parenthesized before the author, date, and server clauses are joined to it, so `transformer OR CRISPR` matches the `(transformer OR CRISPR)` set instead of `CRISPR` alone. An author-only call adds no parentheses (#85).
- **Headings in `content[]`**: `escapeMarkdown` escapes the last `#` of a run that a space or tab precedes and only spaces or tabs follow (`abc #` → `abc \#`), so a title ending in ` #` renders as the `structuredContent` title (#87).
- **`escapeMarkdown`** runs in time linear in the value's length (#89).
