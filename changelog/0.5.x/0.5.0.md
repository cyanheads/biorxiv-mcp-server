# 0.5.0 — 2026-10-28

## Added

- **`biorxiv-guide` Agent Skill**: a published skill covering search syntax, identifier origins, and counting gates for the `biorxiv_*` tools, served over MCP as the resource `skill://biorxiv-guide/SKILL.md` (with the `skill://{+path}` resource template) and shipped in the npm package, the Docker image, and the `.mcpb`.

## Changed

- `@cyanheads/mcp-ts-core` ^0.13.16 → ^0.13.18: MCP SDK 2.4 and the fix for the 0.13.16 per-request HTTP memory leak (0.13.17); `createApp({ skills })`, the Agent Plugins root `plugin.json` and `mcp.json`, and a `.mcpb` without the framework's build-only files (0.13.18)
- Bundle cleaner and packaging check keep the MCP SDK's skills runtime in the `.mcpb` (local port of cyanheads/mcp-ts-core#794)
- **`biorxiv_search_preprints` `server` description** now says it scopes the search itself as well as enrichment; the parameter already restricted the EuropePMC search to that server's preprints.
- **README Getting started** is the hosted `claude mcp add` command, a local `npx` command, and one client-config JSON; the MCP SDK badge reads `^2.4.0`.
- **`CLAUDE.md` and `AGENTS.md`** framework sections, `.github/SECURITY.md`, and the issue forms (one Environment table in the bug report) resynced from mcp-ts-core 0.13.18; `bunfig.toml` `minimumReleaseAge` is 1 day (was 3).

## Fixed

- **Per-request HTTP memory leak**: the HTTP transport no longer retains each request's signal; 0.13.16 leaked about 71 KiB per request, growing the heap under sustained traffic (mcp-ts-core 0.13.17, cyanheads/mcp-ts-core#786).
